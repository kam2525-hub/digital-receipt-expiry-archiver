# 保証書・領収書の一元管理！デジタル保存期間オートチェッカー

家電の保証書や高額な買い物レシートをスマホ撮影するだけで、法的な保存期限やメーカー保証の切れ目を自動通知・管理できるツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/digital-receipt-expiry-archiver/）。
2. 画面の指示に従って操作します。
